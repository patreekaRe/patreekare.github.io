Unity 6 C# Game Architecture

Marvel Champions: Spider-Man vs. Rhino

A digital solo app for Marvel Champions: The Card Game, built from scratch while learning Unity and C#. I play the physical card game, and this project is me translating real rules knowledge into working game logic — a singleton manager architecture (CardEffectManager, PlayerDeckManager, VillainManager, EncounterManager, and more) where UI views subscribe to game state, card effects route through effectId keys, and interrupt cards use async callbacks for player choices like targeting. Currently past a dozen implementation milestones and under active development.

About My Path Into Development

Where I'm Coming From

I hold a BM in Music Education from CSULB and have spent years teaching and writing music professionally. That background shapes how I approach code: break a big, unfamiliar system into parts, understand each one, and rebuild it into something that works reliably — the same process as arranging a song or planning a lesson.

What I've Learned

Through self-directed study (including the 100Devs program) and formal coursework, I've worked from page structure and CSS layout through responsive design, CSS Grid, and animation, and into building a full architecture-driven application in Unity and C#. I'm continuing into JavaScript and full-stack development next.

What I'm Looking For

I'm exploring entry-level front-end and full-stack developer roles. I'm looking for a team where I can keep learning quickly, contribute real work early, and bring the same discipline I've used to ship music and run a game project to shipping software.
